Does the marked noun name an existing state, standing relationship, or ongoing situation rather than a particular occurrence or change presented by this sentence?
Answer Y for an existing state, standing relationship, or ongoing situation.
Answer N for a particular action, communication, decision, change, process, meeting, visit, interview, negotiation, attack, or other occurrence.
In “the report intensified the dispute,” dispute is an existing situation, so answer Y.
In “the dispute began,” began is the change and dispute remains the situation, so answer Y for dispute.
Judge this use of the marked noun only.
Return exactly one character: Y or N.
