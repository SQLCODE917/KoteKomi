# H10 Readiness Checklist

Before starting H10, confirm:

1. H9 main verification receipts exist.
2. H9 follow-up retrospective has been committed.
3. `verification-plan` exists or has an accepted follow-up status.
4. The H10 task manifest includes protected acceptance tests.
5. The H10 verification plan has been generated before implementation.
6. Touched shared harness files have deterministic extra checks.
7. Lifecycle commands for candidate and main are written explicitly before execution.
8. The AGENTS guidance remains short and points agents to deterministic commands.
9. Terra high is only given bounded implementation tasks after docs and acceptance criteria are frozen.
10. Main merge verification includes CI and lifecycle receipts.
